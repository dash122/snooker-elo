# Snooker ELO Flaticon mark

This toolkit is a deterministic resize set of the photographic mark currently used by the app favicon. The 512px project icon is the source artwork; no new visual treatment is introduced.

Available sizes: 16, 32, 48, 64, 96, 128, 180, 192, 256, 512, 1024, and 2048px.

Use the 1024px file for in-app brand placement and the size-matched files for platform icons. The 2048px file is the high-resolution master for future derivatives. Confirm the original Flaticon licence and attribution requirements before distributing the artwork outside this project.
