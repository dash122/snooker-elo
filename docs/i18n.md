# Internationalisation

Locales: `zh-Hant` (source, default) and `en`. Code lives in `lib/i18n/`; UI in `app/components/{I18nProvider,TimeZoneSync}.tsx` and `app/components/shell/LanguageMenu.tsx`.

- **Adding copy:** add the key to `lib/i18n/messages/zh-Hant.ts` first, then `en.ts` (typed against the source keys, so a missing key fails `tsc`). Keys are flat and dotted: `area.thing`. Use `{name}` placeholders, never string concatenation. Plurals: `key_one` / `key_other` plus a numeric `count` param.
- **Using it:** client components `const t = useT()`; server components `const { t } = await getTranslator()` (`lib/i18n/server.ts`). Non-React code (e.g. `lib/notify.ts`) takes a `Translator` or locale as a parameter and never reads request state.
- **Fallback:** a key missing from the active catalogue renders the Traditional Chinese text, never blank.
- **Selection:** `scaa_locale` cookie, default `zh-Hant`; no `Accept-Language` sniffing and no URL prefix. The language menu writes the cookie and calls `router.refresh()`.
- **Time zone:** `scaa_tz` cookie, written by `TimeZoneSync` from the browser's zone; default `Asia/Hong_Kong`. Use `lib/i18n/format.ts` for display. The `hk*` helpers in `lib/availability.ts` still define the club's playing-day window and are not yet migrated.
