# Internationalisation

Locales: `zh-Hant` (source, default) and `en`. Code lives in `lib/i18n/`; UI in `app/components/{I18nProvider,TimeZoneSync}.tsx` and `app/components/shell/LanguageMenu.tsx`.

## Writing copy

Traditional Chinese text **is the message key**. Write the Chinese in the code, wrapped in `t()`:

```tsx
const t = useT();                      // client components
const { t } = await getTranslator();   // server components, route handlers (lib/i18n/server.ts)
<button>{t("儲存變更")}</button>
t("{name} 已加入", { name })           // placeholders are {name}
```

Then add the English to `lib/i18n/messages/en-strings.ts`. `tests/i18n.test.mjs` fails if any `t("…")` / `msg("…")` literal has no entry, if an English string uses a placeholder the source lacks, or if English contains Chinese characters or full-width punctuation. Chinese output is the key itself, so zh needs no catalogue.

- **Plurals** (English only needs them): `"{n} 場": "{n, plural, one {# game} other {# games}}"`. `#` is the number; branches may contain `{other}` placeholders but no nested plurals.
- **Module-level tables** cannot call hooks. Wrap the literal in `msg("…")` (identity, marks it for extraction) and translate where it is rendered: `t(item.label)`, or `useTranslated(table)` for a flat table.
- **Helper functions** that build text take a `Translator` as their first parameter (`describeMatch(t, …)`). `t.locale` is the active locale, for `Intl` formatting.
- **Dates and months:** `lib/i18n/format.ts` and `hkDayLabel(date, locale)` etc. in `lib/availability.ts`. Never hard-code `zh-HK` or `月/日` in a template.
- **Errors thrown from `lib/` or `db/`** stay Chinese (wrap in `msg`); the API route translates with `t(error.message)` before responding.
- Semantic keys (`nav.*`, `lang.*`) live in `messages/zh-Hant.ts` + `messages/en.ts` and are type-checked against each other.
- Fallback: a key with no English entry renders the Chinese source text, never blank.

## Selection

`scaa_locale` cookie, default `zh-Hant`; no `Accept-Language` sniffing and no URL prefix. `LanguageMenu` writes the cookie and calls `router.refresh()`; `useMemo`/`useEffect` that call `t()` must list `t` as a dependency so they refresh on a language change.

## Time zone

`scaa_tz` cookie, written by `TimeZoneSync` from the browser's zone; default `Asia/Hong_Kong`. `lib/i18n/format.ts` formats in a given zone. The `hk*` helpers in `lib/availability.ts` still define the club's playing-day window and are not yet migrated to the viewer's zone.

## Not translated yet

Push notifications (`lib/notify.ts`) and emails (`lib/mailer.ts`) — they need the recipient's locale stored on the member profile. Audit-log entries are stored text and stay in the language they were written in. `/admin` is Chinese only. `public/manifest.json` and the static share images are Chinese.
